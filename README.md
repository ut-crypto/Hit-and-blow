# Hit & Blow 5

0〜9 の重複なし5桁の数字を当てる推理ゲーム(ブラウザで動作)。

- **ひとりで練習**:CPU の数字を当てる
- **オンライン対戦**:同じルームキーを入力した2人で対戦(`?room=キー` 付きの招待リンクも使えます)

## 公開方法(GitHub Pages)

1. リポジトリの **Settings → Pages** を開く
2. **Source** を「Deploy from a branch」、Branch を `master` / `/ (root)` にして Save
3. 数分後に `https://ut-crypto.github.io/Hit-and-blow/` で公開される

## 仕組み

- GitHub Pages は静的ファイルのみ配信するため、通信には [PeerJS](https://peerjs.com/)(WebRTC による P2P 通信)を使用
- 接続相手を探すシグナリングには PeerJS の無料公開クラウドサーバー(`0.peerjs.com`)を使用。アカウント登録は不要
- ルームキーは SHA-256 でハッシュ化した値を接続 ID に使用。先に入室した人がホストになる
- 自分の秘密の数字は相手に送らず、手元で Hit/Blow を判定して結果だけを返す。決着後にお互いの数字を公開し、判定結果に食い違いがないかを自動でチェックする

## 注意

- 公開 PeerJS サーバーは無保証のため、混雑や停止で接続できないことがある
- 一部のネットワーク(企業ネットワーク・一部のモバイル回線など)では P2P 接続が確立できない場合がある(TURN サーバー未使用のため)
